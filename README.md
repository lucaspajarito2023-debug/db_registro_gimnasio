# db_registro_gimnasio 🏋🏻💪🏻

## Proposito esducativo 🧾

 El siguiente repositorio es la base de datos de para el control de registro de un gimnasio, contiene varios ejercicios de consultas y funciones.
 dicho repositorio esta diseñado para la práctica de jóvenes desarrolladores que se van introduciendo en el mundo de la programación y la base de datos.

#### Ramas principales integradas 🛠️

        main: rama de producción, no recibe cambios  directamente.

        dev: rama de prueba y desarrollo.
